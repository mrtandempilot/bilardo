# Fethiye Bilardo Akademisi (taslak)

    npm install
    npm run dev   # http://localhost:3000

İçerik ve fiyatlar: `lib/data.js` (eğitmen adı, telefon, adres, saatlik ücret, indirimler).

Sonraki adımlar:
1. Supabase: `rezervasyonlar` tablosu, `app/api/rezervasyon/route.js` içinde kayıt.
2. iyzico: paket için tek seferlik ödeme, abonelik için iyzico Subscription.
3. Vercel'e deploy.
